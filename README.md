# desk-skills

Skills and automations for the work you already do twice a week. New project, deps, Postman, morning tabs — written once, scheduled or reused.

A skill is what you run. An automation is what runs without you. This repo is both.

I add new skills here every day — the ones that actually automate day-to-day work, not demos.

## What's here

| | Skill | Automation |
|---|---|---|
| Scratch project | `mern-init` — your structure, auth first | — |
| Dependencies | `dep-updates` — apply only after you say yes | Check → email the report |
| New API | `postman-sync` — collection in Postman, only the new request | — |

Copy a folder from `skills/` into `~/.cursor/skills/`.
